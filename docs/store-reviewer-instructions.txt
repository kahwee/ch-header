No login or payment. Clone https://github.com/kahwee/ch-header and run node scripts/header-check.js. Open http://127.0.0.1:3002/. Import docs/examples/local-profile.json in the popup (starts off). Enable it, reload, and click Run checks: requestHeader=enabled; responseHeader=modified. Disable, reload and rerun: requestHeader=(absent); responseHeader=original. Leave it off and stop the server. Also test create/rename/duplicate/delete/Undo and JSON export. No URL rules means no requests change.
