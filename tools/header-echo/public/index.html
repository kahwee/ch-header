Check your headers

See what reaches this Cloudflare Worker and what your browser receives back.

  1. In ChHeader, allow this hostname.
  2. Add request header X-ChHeader-Test: hello-gecko and response header X-ChHeader-Response: modified.
  3. Choose URL pattern and enter /headers/match. Turn the profile on and approve access. Reopen ChHeader, select that profile and enable it again if needed.
  4. Run the checks. The matching path should change; the other path and redirect should stay unchanged.

Use demo values only. This page displays Accept, Content-Type, X-Env and X-ChHeader-Test. Other headers are omitted, including authorization and cookies. Requests still reach Cloudflare; use a local tester for secrets. This Worker has no application logs, analytics or storage.

“Request headers” come from the Worker. “Response header” comes from your browser. A missing value means the rule did not apply; this page never sets the test headers itself.
